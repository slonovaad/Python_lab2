## Алгоритм решения
  1. Пользователь единой строкой вводит в терминал команду, опции и аргументы (пути).
  Программа записывает в лог время ввода и введённую строку
  2. Программа разбивает (**parse.parse**) введённую строку на команду, список опций и список путей
        - Если строка пустая, программа записывает сообщение об этом в лог и переходит к шагу 1
        - Если введённая команда - exit, программа записывает сообщение об этом в лог и прекращает работу
  3. Вызывается функция, соответствующая введённой команде, ей передаются в качестве аргументов
  список опций и список путей
        - Если введённой команды не существует, в терминал и лог записывается сообщение об ошибке, программа
        переходит к шагу 1. (**error_messanges.command_not_found_error_message**)

### Формат ввода команд
```<команда> <ключи> <пути>```

Формат ввода ключа:

```-<буква>```

Для ввода нескольких ключей необходио либо ввести их в указанном формате через пробел,
либо указать несколько букв.

Путь может быть абсолютный или относительный.

Если путь содержит пробелы, то вводится в двойных кавычках. Иначе может вводиться как в них, так и без

### Команды и синтаксис
1. ```cd <путь к директории>```
    - Переход в указанную директорию
    - Поддерживает ```..``` для перехода в родительскую директорию
    - Поддерживает ```~``` для перехода в домашнюю директорию
    - Поддерживает ```/``` или ```\``` для перехода в корневую директорию

2. ```ls <опции> <путь к директории>```
    - Вывод содержимого указанной директории
    - Если путь не указан, выводит содержимое текущей директории
    - Поддерживает опцию ```-l``` для вывода подробной информации о файлах
    (название, размер, дата последнего изменения, права доступа)
    - При выводе названия директорий выделяются синим

3. ```cat <путь к файлу>```
    - Вывод содержимого указанного файла

4. ```mv <источник> <назначение>```
    - Перемещает файл или директорию из источника в назначение

5. ```cp <опции> <источник> <назначение>```
    - Копирует файл или директорию из источника в назначение
    - Поддерживает опцию ```-r``` для рекурсивного копирования директорий вместе с содержимым

6. ```rm <опции> <файл или директория>```
    - Удаяляет указанный файл или директорию
    - Поддерживает опцию ```-r``` для рекурсивного удаления директорий вместе с содержимым
    - При удалении директории запрашивает подтверждение ```[y/n]```
    - Запрещено удалять корневую (```/```) или родительскую (```..```) директорию
