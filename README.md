# Лабораторная работа 2

* **Цель:** Написать на Python мини-оболочку с основными командами управлния файлами и каталогами,
 освоить работу с файловой средой и логирование
* **Библиотеки:** *os*, *os.path*, *pathlib*, *sys*, *shutil*, *logging*, *re*,
*zipfile*, *tarfile*
* **Допущения:**
  - Выбран интерактивный формат приложения
  - Путь, в котором содержатся пробелы, обязательно вводится в двойных кавычках
  - В названии файлов и директорий нельзя использовать двойные кавычки
  - Синтаксис шаблона в grep аналогичен синтаксису регулярных выражений в python

* **Добавленный функционал:**
  - Цветной вывод:
    - В выводе текущей директории зелёным выделена домашняя директория, синим - остальной путь
    - В выводе ```ls``` синим выделены директории
    - В выводе ```grep``` красным выделены вхождения шаблона, голубым - номер строки, при вызове с опцией ```-r``` названия файлов выделены фиолетовым

## Алгоритм решения
  1. Пользователь единой строкой вводит в терминал команду, опции и аргументы (пути).
  Программа записывает в лог время ввода и введённую строку
  2. Программа разбивает введённую строку на команду, список опций и список путей
        - Если строка пустая, программа записывает сообщение об этом в лог и переходит к шагу 1
        - Если введённая команда - exit, программа записывает сообщение об этом в лог, записывает команду и её порядковый номер в файл ```.history``` и прекращает работу (переход к шагу 8)
  3. Введённая строка и порядковый номер команды записываются в файл ```.history```
  3. Вызывается функция, соответствующая введённой команде, ей передаются в качестве аргументов
  список опций и список аргументов (путей)
        - Если введённой команды не существует, в терминал и лог записывается сообщение об ошибке, программа переходит к шагу 1
  4. Внутри функции, реализующей функционал команды, проходит проверка на корректность аргументов и опций (количество, существуют ли такие опции), при необходимости на существование путей и на то, являются ли они файлом/директорией
        - ```ls```: Программа получает список файлов/директорий, находящихся в указанной директории, и выводит его
        - ```cd```: Осуществляет переход в указанную директорию
        - ```cat```: Открывает необходимый файл, читает и выводит его содержимое
        - ```cp```: Если целевого файла/каталога не существует, создаёт его. Копирует исходный файл/каталог. Если целевой файл/каталог существует, перезаписывает его, предварительно сохраняя изначальную версию во временный каталог ```.trash``` с названием в формате ```<порядковый номер команды>_<название файла/каталога>```. Записывет введённую пользователем команду, пути и порядковый номер команды во временный файл ```.undo_history```
        - ```mv```: Если родительских директорий целевого файла/каталога не существует, создаёт их. Переименовывает исходный файл/каталог. Если целевой файл/каталог существует, перезаписывает его, предварительно сохраняя изначальную версию во временный каталог ```.trash``` с названием в формате ```<порядковый номер команды>_<название файла/каталога>```. Записывет введённую пользователем команду, пути и порядковый номер команды во временный файл ```.undo_history```
        - ```rm```: Сохраняет файл/директорию во временный каталог ```.trash``` с названием в формате ```<порядковый номер команды>_<название файла/каталога>```. Удаляет указанный файл/каталог. Записывет введённую пользователем команду, путь и порядковый номер команды во временный файл ```.undo_history```
        - ```zip```, ```tar```: Если родительских директорий целевого файла/каталога не существует, создаёт их. Создаёт архив из исходного файла/каталога. Если целевой файл существует, перезаписывает его.
        - ```unzip```, ```untar```: Распаковывает архив в текущий каталог
        - ```grep```: Если вызывается для файла, считывает построчно его содержимое. Если для директории, проходит по её содержимому и для каждого файла построчно считывает содержимое. Для каждой строки ищет соответствия с шаблоном. Если они есть, выводит строку и её номер.
        - ```history```: Если не указано число, выводит всё содержимое файла ```.history```. Если указано число N, выводит его последние N строк.
        - ```undo```: Открывает временный файл ```.undo_history```. Если файла не существует или он пустой, выводит сообщение о невозможности выполнить команду и записывает ошибку в лог. Иначе считывает последнюю строку из файла. Разделяет её на порядковый номер команды и введённую пользователем строку без учёта опций. Полученную строку разбивает на команду и пути. В зависимости от команды:
          - ```rm```: Восстанавливает из временного каталога ```.trash``` необходимый файл/каталог, находя его по порядковому номеру команды в названии.
          - ```cp```: Удаляет созданный файл/каталог. Если существует требующий восстановления файл/каталог с соответствующим номером команды в названии во временном каталоге ```.trash```, восстанавливает его.
          - ```mv```: Изменяет имя на исходное. Если существует требующий восстановления файл/каталог с соответствующим номером команды в названии во временном каталоге ```.trash```, восстанавливает его.

          Если было восстановление, удаляет восстановленный файл из каталога ```.trash```. Удаляет последнюю строку из ```.undo_history```
  5. Программа записывает информацию об успешном результате работы или ошибке программы в лог.
  6. Возвращение к шагу 1.
  7. При прекращении работы (команда ```exit```) программа удаляет каталог ```.trash``` и файл ```.undo_history```

## Инструкция к использованию

### Запустить
```python -m src.main```

### Остановить программу
```exit```

### Формат ввода команд
```<команда> <опции> <пути>```

Формат ввода опции:

```-<буква>```

Для ввода нескольких опций необходимо либо ввести их в указанном формате через пробел,
либо указать после минуса несколько букв без пробелов *(например, "-ir")*.

Путь может быть абсолютный или относительный.

Если путь содержит пробелы, то вводится в двойных кавычках. Иначе может вводиться как в них, так и без

### Команды и синтаксис
1. ```cd <путь к директории>```
    - Переход в указанную директорию
    - Поддерживает ```..``` для перехода в родительскую директорию
    - Поддерживает ```~``` для перехода в домашнюю директорию
    - Поддерживает ```/``` или ```\``` для перехода в корневую директорию


2. ```ls <опции> <путь к директории>```
    - Вывод содержимого указанной директории
    - Если путь не указан, выводит содержимое текущей директории
    - Поддерживает опцию ```-l``` для вывода подробной информации о файлах
    (название, размер, дата последнего изменения, права доступа)
    - При выводе названия директорий выделяются синим


3. ```cat <путь к файлу>```
    - Вывод содержимого указанного файла


4. ```mv <источник> <назначение>```
    - Перемещает файл или директорию из источника в назначение


5. ```cp <опции> <источник> <назначение>```
    - Копирует файл или директорию из источника в назначение
    - Поддерживает опцию ```-r``` для рекурсивного копирования директорий вместе с содержимым


6. ```rm <опции> <файл или директория>```
    - Удаяляет указанный файл или директорию
    - Поддерживает опцию ```-r``` для рекурсивного удаления директорий вместе с содержимым
    - При удалении директории запрашивает подтверждение ```[y/n]```
    - Запрещено удалять корневую (```/```) или родительскую директорию


7. ```tar <источник> <назначение>```
    - Создаёт из файла или директории источника tar архив
    - Назначение - либо файл ```.tar.gz```, либо директория (путь заканчивается на "/", файл-назначение создастся автоматически)


8. ```zip <источник> <назначение>```
    - Создаёт из файла или директории источника zip архив
    - Назначение - либо файл ```.zip```, либо директория (путь заканчивается на "/", файл-назначение создастся автоматически)


9. ```untar <.tar.gz архив>```
    - Распаковывает tar архив в текущую директорию


10. ```unzip <.zip архив>```
    - Распаковывает zip архив в текущую директорию


11. ```grep <шаблон> <путь>```
    - Ищет в файле совпадения с шаблоном
    - Если в шаблоне нет пробелов, можно писать его без двойный кавычек
    - Если шаблон содержит пробелы, обязательно писать его в двойных кавычках
    - Синтаксис шаблона аналогичен синтаксису регулярных выражений в python
    - Поддерживает опцию ```-i``` для поиска без учёта регистра
    - Поддерживает опцию ```-r``` для рекурсивного поиска в подкаталогах
    - Выводит название файла (при рекурсивном поиске), номер строки и строку с выделенными вхождениями шаблона


12. ```history <N>```
    - Выводит последние N введённых команд
    - Если не передан аргумент N, выводит все хранимые (по умолчанию 20)
    - История сохраняется между запусками


13. ```undo```
    - Отменяет последнюю команду из списка ```cp```, ```mv```, ```rm```
    - Работает в рамках одного запуска
    - Если не было ни одной команды из спика ```cp```, ```mv```, ```rm```, выводит ошибку
